# Global Working Instructions

## Reasoning
- Use first-principles thinking.
- Do not assume my goals, constraints, or intended approach are already clear.
- Start from the underlying problem and verify the objective before proposing a solution.
- If requirements are ambiguous, pause and ask for clarification instead of guessing.

## TypeScript
- For any TypeScript task, always load and follow the `typescript-project-specifications` skill before writing code.

## Solutions
- Do not propose compatibility layers, patchwork fixes, or workaround-based designs.
- Do not over-engineer; prefer the shortest correct implementation path.
- Do not add fallback, downgrade, or extra solution branches unless I explicitly request them.
- Ensure the proposal is logically sound and validated across the full end-to-end workflow.
